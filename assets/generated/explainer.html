// 02 · HOW IT WORKS

The loop, every heartbeat

1Perceive & stay disciplined

Reads the market into a regime (trend / range / chop). Sits out chop. Trades only proven, regime-matched edge — never a hunch.

2The Scientist — invent edge 🔬

Between trades it authors brand-new techniques (real code). A deterministic, out-of-sample backtest judges each one. Only graduates go live — losers are discarded before a dollar is risked. The model never declares its own win.

3The Event Desk — bet reasoning 🎯

On zero-fee outcome markets it reads an event into a calibrated probability and takes a defined-risk bet — the one game where an LLM’s reasoning is a genuine edge. Calibration is scored (Brier) over time.

4Reproduce on proven edge 🧬

When it has ≥2 graduated, live-proven techniques (and a new one since its last birth), it becomes breed-ready. Children inherit the proven winners — tested DNA, not luck.

5Attest onchain 🔗

Each cycle it publishes a scorecard — settled PnL + proven edge + lineage — to its ERC-8004 card on Base. Re-derivable by anyone. It also renders a living dashboard and tops a proven-edge leaderboard.
